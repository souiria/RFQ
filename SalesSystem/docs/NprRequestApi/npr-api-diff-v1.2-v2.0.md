# NPR Request API — Differences (v1.2 vs v2.0)

## Overview

This document highlights the **schema-level and payload differences** between **v1.2** and **v2.0** of the NPR Request API.

- ✅ API endpoint remains unchanged  
- ✅ Core business flow remains unchanged  
- ⚠️ Payload structure has **breaking changes**

---

## Semantic / Behavioral Changes

### 1. Request ID Handling

* v1.2: Provided in request
* v2.0: Generated by system (response only)

✅ Cleaner API design and reduced client responsibility

***

### 2. Platform & Program Removal

* v1.2: Required fields
* v2.0: Removed entirely

✅ Likely derived internally from `ProjectCode`

***

### 3. Quantity Model Simplification

* Removed: `VehicleTotalQuantity`
* Retained: `QtyPerVehicle`

✅ Simplifies payload and validation

***

### 4. Unit of Measure Standardization

* `SEWSEUnitOfMeasurement` → `BOMUnitOfMeasurement`

✅ Aligns naming with BOM/domain terminology

***

## Breaking Changes Summary

| Change                        | Type     | Impact                            |
| ----------------------------- | -------- | --------------------------------- |
| Remove `RequestID`            | Breaking | Must not send anymore             |
| Remove `VehicleTotalQuantity` | Breaking | Must stop sending                 |
| Remove `PlatformName`         | Breaking | Must remove from payload          |
| Remove `ProgramName`          | Breaking | Must remove from payload          |
| Rename UOM field              | Breaking | Update request + response parsing |
